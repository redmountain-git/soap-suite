# @redmountainsoap/calculator-workbench

`<recipe-vector-workbench>` combines the public calculator core with the framework-neutral vector widgets.

Set its `document` property to a `CalculatorDocument`. Committed edits emit a bubbling, composed `calculator-change` event containing the next document and the change source.

The calculator is an educational aid. Verify formulations independently and follow current lye-handling safety guidance.
