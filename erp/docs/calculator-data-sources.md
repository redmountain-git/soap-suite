# Reference Data

The initial oil profiles and sodium-hydroxide SAP values are approximate
educational defaults carried forward from the Red Mountain Soap prototype.
They represent typical values, not supplier- or lot-specific laboratory data.

Until the table below is completed with reviewed redistribution-compatible
sources, the application and package APIs must label these values as
approximate and must not describe their output as production-grade evidence.

| Dataset                  | Current status               | Required release treatment              |
| ------------------------ | ---------------------------- | --------------------------------------- |
| Fatty-acid profiles      | Approximate prototype values | Display educational-data notice         |
| NaOH SAP values          | Approximate prototype values | Require independent verification        |
| Preferred quality ranges | Heuristic guidance           | Describe as guidance, not safety limits |
| Density defaults         | Generic fallbacks            | Allow document-specific overrides       |
